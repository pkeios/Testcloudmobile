# Pixel Pitbull

Juego web 8-bit: Bruno, un pitbull negro con una mancha blanca en el pecho, corre 600 m saltando obstáculos (bocas de incendio, conos y cajas), recoge huesos y, como premio final, encuentra su plato de comida.

## Cómo jugar

- **Espacio / ↑ / W**: saltar. Mantén pulsado para saltar más alto.
- **Móvil**: toca la pantalla del juego.
- Tienes 3 vidas. Cada hueso suma 25 puntos; llegar a la comida suma 300.

## Ejecutar

Es un único archivo `index.html` sin dependencias: ábrelo en el navegador.

Para publicarlo con GitHub Pages: *Settings → Pages → Deploy from a branch* y elige la rama y la carpeta raíz.

# Corre Que Viene el Diegote

Carpeta `diegote/`. Variante del mismo juego: el Diegote es un jugador de fútbol americano con un oso azul en el pecho que corre con la pelota las 100 yardas del campo. Su dificultad: tiene **tres piernas** (la tercera, color piel y más grande, va dando zancadas) y de vez en cuando se le traban.

- **Espacio / ↑ / W**: saltar (mantén para más altura).
- **S / ↓**: desenredar las piernas cuando aparece el aviso. Si no llegas a tiempo, tropieza y pierde una vida.
- En móvil hay botones **PIERNAS** y **SALTAR** debajo del juego.
- Al cruzar la end zone le espera el premio: un abrazo doble a la puerta del burdel.

Con GitHub Pages queda en `/diegote/`.
