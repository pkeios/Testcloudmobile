# Pixel Pitbull

Juego web 8-bit: Bruno, un pitbull negro con una mancha blanca en el pecho, corre 600 m saltando obstáculos (bocas de incendio, conos y cajas), recoge huesos y, como premio final, encuentra su plato de comida.

## Cómo jugar

- **Espacio / ↑ / W**: saltar. Mantén pulsado para saltar más alto.
- **Móvil**: toca la pantalla del juego.
- Tienes 3 vidas. Cada hueso suma 25 puntos; llegar a la comida suma 300.

## Ejecutar

Es un único archivo `index.html` sin dependencias: ábrelo en el navegador.

Para publicarlo con GitHub Pages: *Settings → Pages → Deploy from a branch* y elige la rama y la carpeta raíz.
